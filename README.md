# Tkeyro Voice App

A desktop voice changer app for gaming with AI-powered text-to-speech.

Type or speak, and hear it back in any voice — from free Edge voices to premium Fish Audio voices. Built for gamers who want to roleplay, have fun, or just sound different in-game.

## Features

- **Text-to-Speech** — type text or use your microphone, and the app speaks it in your chosen voice
- **Edge Voices (Free)** — 15 high-quality voices included at no cost
- **Fish Audio Voices (Pro)** — thousands of community voices with credits
- **Voice Search** — browse and add Fish Audio voices directly from the app
- **Callouts** — bind voice lines to hotkeys for quick in-game callouts
- **Quotes** — save and cycle through voice lines with a single keypress
- **Recording** — capture voice outputs as MP3 files
- **Virtual Cable Support** — route your voice into any game or app via VB-Audio Virtual Cable

## Download

Go to [Releases](https://github.com/Tkeyro/TkeyroVoiceApp/releases) and download the latest `.zip` file.

## Setup

1. **Install Python 3.10+** from [python.org/downloads](https://www.python.org/downloads/)
   - **Important:** Check "Add Python to PATH" during installation
2. **Extract** the downloaded `.zip` file anywhere (Desktop, Documents, etc.)
3. **Open** the `TkeyroVoiceApp` folder
4. **Double-click `install.bat`** to install required packages (first time only)
5. **Double-click `start.bat`** to launch the app
6. **Create an account** or sign in

## Virtual Cable (Optional)

To use your AI voice in games:

1. Download [VB-Audio Virtual Cable](https://vb-audio.com/Cable/) (free)
2. In the app, go to **Audio** tab and set the virtual cable as your **TTS Output Device**
3. In your game, select the virtual cable as your **microphone input**

## Requirements

- Windows 10/11
- Python 3.10 or newer
- Internet connection (for voice generation and account features)
